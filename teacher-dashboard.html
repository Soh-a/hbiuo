Welcome, Teacher!

Use this dashboard to manage all your classroom activities efficiently. Navigate using the sidebar to access different sections:

  • Attendance Calculator: Upload photos of the class register to calculate attendance automatically.
  • Exam Upload: Upload scanned exam tables to keep track of student marks.
  • Fees: View monthly fee summary and track pending payments.
  • Teacher Timetable: Add, view, and manage your class timetable.

All tools are designed to work in-browser and are mobile-friendly. Future versions will integrate with Firebase to save data online and allow real-time updates.
